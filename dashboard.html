Your idea

AgentGraph: an open-source plugin that draws the agent's workflow

Any agent runtime emits events. AgentGraph turns them into one normalised trace and renders it live as a graph: steps, tool calls, sub-agents, data queries, model calls and the evidence each answer rests on. Proposal below is mine, not from the organisers.

Why Track 02 fits

  • The track asks for answers backed by evidence. The graph's "why this answer" path is that evidence, shown.
  • Impact (30) and Demo (15) are 45 of 100 points. A live graph of an agent working is a strong demo.
  • Sponsor tech (10) becomes visible as typed nodes: Zetaris queries and Meterless/Nemotron model calls get their own colour in the graph.

Risks to settle first

  • It must be an agent. Rules ask for an agent that does work, not only a tool. Ship a reference agent that investigates a real question across data sources and is drawn by AgentGraph as it runs.
  • Sponsor integration is required. The repo says Zetaris and Meterless must be used. Check in HackOS what a minimal integration needs.
  • Scope. Ship one adapter well (Claude Code hooks) plus the generic JSONL format. Add others after the demo.
